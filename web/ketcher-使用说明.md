# 画板（Ketcher）使用说明

这是本软件的**画板零件**：把分子结构画出来，然后导出成 SMILES 文本，交给后面的"转换 / 预测"功能处理。
**全程不需要联网**，画的东西一个字节都不会离开这台电脑。

---

## 一、怎么打开

画板必须通过本机的网页服务打开，**不要直接双击 html 文件**（那样浏览器会拦住画板引擎）。

### 方法 1：跟着整个软件一起用（推荐）

双击项目根目录的 `启动.bat`，浏览器会自动打开主页面，画板就在左边。

### 方法 2：单独看看画板（调试用）

在本项目的 `web` 目录里起一个本地小服务：

```bash
cd C:/Users/zzl/Desktop/hx/web
python -m http.server 8899 --bind 127.0.0.1
```

然后在浏览器地址栏输入：

```
http://127.0.0.1:8899/ketcher-test.html
```

打开后会先显示"正在加载画板…"，约 **1 秒**后消失，出现工具条和白色画布，右上角状态变成绿色的「画板就绪」。

> 想关掉服务，回到那个终端按 `Ctrl + C` 即可。

## 二、界面速览

| 位置 | 是什么 |
|---|---|
| 最上面一栏 | 本项目加的：**「导出 SMILES」按钮** + 状态提示 |
| 第 2 行（浅色图标条） | Ketcher 自己的工具：新建、打开、保存、撤销/重做、框选、删除、放大缩小、旋转、清除等 |
| 左侧竖条 | 画图工具：单键、双键、三键、环、电荷、原子标签、S-基团、箭头（反应箭头）、加号等 |
| 右侧元素表 | H / C / N / O / S / P / F / Cl / Br / I / Pt 等，点一下就把当前画笔画成该元素 |
| 底部横向一排 | 环模板：苯环（第一个六边形）、环戊烷、环己烷、三角形、正方形等，点一下放到画布上 |
| 画布正下方 | 本项目加的结果框：显示导出出来的 SMILES 文本 |

## 三、怎么画

**画一个苯环**
1. 在底部环模板里点第一个"六边形"（苯环）。
2. 在白色画布上点一下，苯环就放上去了。

**免费试用小贴士**：打开页面后，可以直接画，也可以按下面的"验证是否正常"一节试试。

**画一条键**
1. 左侧点一下单键工具（默认就是它）。
2. 在画布上按住鼠标拖一条线；松手后再拖，就会接着上一个原子继续画链。

**加原子/换元素**
1. 先在右侧元素表点中要的元素（比如 N）。
2. 再用鼠标点画布上某个原子，那个原子就变成 N；点在空白处则是新建一个 N 原子。

**移动 / 删除**
- 左上角的箭头工具（框选）可以拖动原子和基团。
- 选中后按 `Delete`，或用橡皮擦工具点一下要删的东西。

## 四、怎么导出 SMILES

1. 在画布上把结构画好。
2. 点最上面的 **「导出 SMILES」** 按钮。
3. 画布下方文本框里就会出现这个结构的 SMILES 文本，例如画了苯环就显示 `c1ccccc1`。
4. 用鼠标选中文本框里的内容，`Ctrl + C` 复制走即可（文本框是只读的，防止误改）。

按钮旁边的状态提示会告诉你结果：

- 「已导出 SMILES」—— 成功。
- 「画板是空的」—— 画布上还没有结构，先画一个。
- 「导出失败：…」—— 出错了，把提示内容反馈给开发者。
- 「画板尚未就绪」—— 还在加载中，等状态变成绿色再点。

## 五、验证它是否正常（30 秒自检）

1. 打开测试页，等状态变成绿色的「画板就绪」。
2. 在底部环模板点一下六边形，在画布上点一下 —— 出现一个苯环。
3. 点「导出 SMILES」。
4. 文本框应显示：`c1ccccc1`

再试一个稍复杂的：画完苯环后，用右侧元素表配合工具随便接一个COOH（羧基），
导出后 SMILES 应该形如 `OC(=O)c1ccccc1`（顺序可能不同，但都是同一个分子）。
只要文本能出来，就说明画板和化学引擎都正常。

## 六、常见问题

**Q：页面一直停在「正在加载画板…」？**
A：说明画板引擎没能启动。请确认是通过 `http://127.0.0.1:...` 打开的，而不是双击 html 文件
（`file://` 打开时浏览器会禁止引擎所需的后台线程）。另外打开浏览器控制台看看有没有红色报错。

**Q：点了「导出 SMILES」没反应？**
A：看按钮旁边的状态文字。若显示「画板尚未就绪」，说明还在加载，稍等再点。

**Q：SMILES 是什么？**
A：用一串纯文本表示分子结构的国际通用写法，例如苯是 `c1ccccc1`、乙醇是 `CCO`。
本软件的各个零件之间就靠它互相传递分子。

**Q：导出的 SMILES 跟我画的不完全一样？**
A：正常。引擎会按标准规则重新规范化，同一个分子可能有多种合法写法，含义完全相同。

**Q：会不会偷偷联网？**
A：不会。已实测：打开并画图全程只访问了本机的 HTML、CSS、JS 三个文件和一个本机生成的
`blob:` 后台线程，对外请求 **0 条**（详见同目录 `获取记录.md` 第五节）。
